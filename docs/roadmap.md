# Roadmap

Core product loop (create/join a room, WebRTC voice, WhatsApp-style share
invites, the new-tab overlay with auto-hide/minimize/reopen) is implemented —
see the README's "Known limitations" section for what's genuinely still open:
a TURN relay for restrictive networks, persistence/auth, Firefox support,
branded icon artwork, and testing beyond a handful of simultaneous
participants. Treat this file as a pointer to that list rather than a
separate one to keep updated in parallel.
